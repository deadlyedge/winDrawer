# 阶段七建议：文件列表与设置交互收尾

我检查了当前实现和 TODO。工作树中 **`docs/TODOs.md` 已有未提交修改**，内容正是这五项 TODO；我保留了它，没有改动源码或文档。

## 已核实的现状

- 抽屉目前先枚举全部直接子项，再按名称分别排序目录和文件；随后为**每个项目**生成缩略图或 Shell 图标，最后一次性加入 ListView。因此日期排序需要先取得全部直接子项的时间元数据，但昂贵的图像生成可以延迟。
- `ScrollableListView` 已提供 `ViewportChanged` 通知；抽屉加载也已有取消令牌和 generation 检查，可作为可视区加载的基础。
- 主设置窗体以 `settings.Show(this)` 显示；抽屉设置对话框以 `dialog.ShowDialog(this)` 显示。它们目前没有按主窗口坐标明确定位。
- 抽屉设置使用无边框自绘标题栏，右上角有自定义关闭图标；Folder 路径目前是可编辑文本框，与 Browse 按钮处于同一行。
- 设置中的 Behavior 项有现成的保存、取消与 Default 流程；配置 schema 由 `SettingsSnapshot` 和 `SettingsRepository` 负责。

## 建议分阶段实施

### 阶段 7.1：按日期排序

1. 将“日期”定义为文件或目录的最后修改时间，使用 `LastWriteTimeUtc` 排序，避免本地时区切换影响先后顺序。
2. 目录与文件**完全混排**；日期相同则按名称 `OrdinalIgnoreCase` 升序，仍相同再按完整路径 `Ordinal` 升序稳定排序。
3. 单个子项无法读取时间信息时记录诊断，并把该项排在所有可读时间之后，不让一个坏条目中断整个列表刷新。

**验收：** 用临时目录设置不同时间戳，验证目录与文件混排且整体降序；验证相同时间戳的稳定排序、时间读取失败回退、刷新后顺序一致。

> **排序语义（已确认）：** 目录与文件全体混排，不再保留“目录在前、文件在后”。

### 阶段 7.2：抽屉图标与缩略图延迟加载

1. 先收集并排序直接子项的轻量元数据，不递归扫描。
2. 先显示完整项目列表和占位图标；仅为可视区及少量预取范围加载缩略图和 Shell 图标。
3. 利用现有 `ViewportChanged`、取消令牌和 generation 机制处理快速滚动、刷新、DPI 变化和窗口关闭；图像生成放在线程池，控件及 `ImageList` 更新留在 UI 线程。
4. 评估缓存上限和离开可视区后图像的释放策略；不在实现前假定 `ListView.VirtualMode` 适用于当前图标视图。
5. 保留图片缩略图失败时回退到 Shell 图标的现有行为，并处理单个文件被删除或拒绝访问的情况。

**验收：** 大目录初次显示不再为全部条目同步生成图标；滚动到新区域时图标逐步出现；快速滚动、刷新和关闭不显示过期缩略图、不崩溃、不锁源文件；图像、ImageList 和取消令牌能正确释放。

> 日期排序需要先读取所有直接子项的元数据，因此本阶段的“lazyload”重点是延迟加载图像资源，而不是延迟发现列表条目。

### 阶段 7.3：Always on top 设置

1. 在主设置窗体的 Behavior 分区加入开关，并明确持久化字段。建议采用 `startup.always_on_top`，布尔值默认 `false`。
2. 把字段贯穿设置模型、配置读取/保存、嵌入默认模板和配置文档；保持缺字段时默认关闭，不做旧配置迁移。
3. 通过 `Form.TopMost` 应用设置，并遵守当前 Save/Cancel 预览语义：切换立即预览，Cancel 恢复原状态，Save 保存；Default 则按既有语义恢复模板值。
4. 验证 TopMost 不改变托盘入口、隐藏/显示、任务栏归属和窗口锁定。

**验收：** 开关切换即时生效；Cancel 可恢复，Save 后重启仍保持；Default 重置结果正确；不会出现无意置顶的辅助窗口。

> **需要确认的作用范围：** 建议把选项应用于主工作窗体和当前抽屉内容窗体，不把设置面板本身设为独立的 TopMost 窗口。如果你只希望主窗体置顶，应在实施前缩小范围。

### 阶段 7.4：两个设置窗口的初始位置

1. 在设置窗体创建时，将 `StartPosition` 设为 Manual，初始左上角设为主窗口位置 `(X + 100, Y + 100)`。
2. 覆盖主设置窗体和抽屉设置对话框；不保存这两个设置窗体的位置，不影响主窗口位置或抽屉尺寸配置。
3. 将目标位置限制在主窗口所在显示器的工作区内，避免多显示器、负坐标、DPI 缩放或窗口尺寸较大时整窗跑出屏幕。
4. 设置窗体重新打开时重新根据主窗口当前坐标计算，不复用旧位置。

**验收：** 从不同主窗口位置打开两个设置窗体，初始位置偏移符合预期；多显示器边缘和不同 DPI 下窗口仍完整可见；主窗口移动后再次打开会采用新位置。

### 阶段 7.5：抽屉设置路径与关闭入口

1. 移除自绘标题栏右上角的关闭图标，但保留窗口标题和拖动区域的必要布局。
2. Folder 路径改成不可直接编辑的显示控件；点击路径区域与点击 Browse 执行同一个选目录流程。保留键盘可操作性、指针提示和无障碍名称。
3. 将 Browse 放在路径下方独立一行并适当加宽，避免缩窄时路径和按钮互相挤压。
4. 保留 Save、Cancel 和 Delete 的现有语义；Delete 仍需按现有确认流程工作。Escape 或 Alt+F4 应按 Cancel 处理，不提交草稿。

**验收：** 路径不能被键入修改；点击路径和 Browse 打开相同的目录选择器；取消选择不改变草稿路径；Save/Cancel/Delete 的已有行为不回归；不同 DPI 和较长路径下不裁切、不重叠。
